# Aulas

Todo material de aula deve ficar organizado por disciplina e seguir este formato:

`aulas/<disciplina>/AAAA-MM-DD-<tema-em-kebab-case>.md`

Regras obrigatórias:

- Use uma pasta de disciplina em letras minúsculas e kebab-case, como `direito-administrativo` ou `direito-constitucional`.
- Use a data da aula ou da preparação indicada no próprio material e um tema curto em kebab-case.
- Não crie aulas diretamente na raiz de `aulas/` nem use nomes como `AULA_01_Tema.md`.
- Ao encontrar uma aula fora do padrão, mova/renomeie o arquivo existente, preservando seu conteúdo; não mantenha cópias duplicadas e atualize referências ao caminho antigo.
- Antes de criar uma aula, confira esta convenção e os arquivos existentes.

Exemplos:

- `aulas/direito-administrativo/2026-11-04-introducao-direito-administrativo.md`
- `aulas/direito-constitucional/2026-11-04-introducao-direito-constitucional.md`

Use o prompt `/aula` para preparar novos materiais.
